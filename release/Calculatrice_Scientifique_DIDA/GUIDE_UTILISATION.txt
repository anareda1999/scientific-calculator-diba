--------------------------------------------------------------------------------
  4. LES 7 MODULES  /  THE 7 MODULES
--------------------------------------------------------------------------------

  4.1 CONVERTISSEUR  /  CONVERTER
      Poids | Devise | Volume | Surface | Distance
      Tapez une valeur : la conversion se fait automatiquement.
      Bouton "Inverser" pour echanger les unites.
      Type a value - the conversion happens automatically.

  4.2 EQUATIONS  /  EQUATIONS   (5 onglets)
      1er degre   :  ax + b = 0
      2eme degre  :  ax^2 + bx + c = 0   (avec le discriminant Delta)
      Expression  :  evaluez n'importe quelle expression en x
      Racines     :  recherche numerique de racines sur un intervalle
      Systeme     :  systemes lineaires 2x2 et 3x3
      Les coefficients acceptent : sin cos tan cot log ln exp sqrt pi e

  4.3 GRAPHIQUE  /  GRAPHING   (style Desmos)
      - Le trace se dessine tout seul pendant que vous tapez
      - Plusieurs expressions, chacune avec sa couleur (bouton X pour supprimer)
      - CURSEURS : ecrivez "a = 3" pour creer un curseur, puis glissez-le
        sur le graphique ou dans le panneau pour voir la courbe changer
      - Glisser = deplacer | Molette = zoom | Boutons Zoom +/- 
      - Coordonnees x,y affichees sous le curseur
      - Types supportes :
            y = x^2              (fonction)
            y = sin(x)           (fonction)
            x^2 + y^2 = 25       (courbe implicite -> cercle)
            x = 5               (droite verticale)
            (3, 4)              (point)
            a = 3               (curseur)
      - Syntaxe Desmos : 2x  3x+2  2sin(x)  (x+1)(x-1)  x^2  x²

  4.4 FORMULES  /  FORMULAS
      9 formules scientifiques pretes a l'emploi :
        Formule du second degre | Aire du cercle | Aire du rectangle |
        Aire du triangle | Volume de la sphere | Volume du cylindre |
        Loi d'Ohm | Force | Energie cinetique

  4.5 MATRICES  /  MATRICES
      Matrices 2x2, 3x3 ou 4x4 :
        determinant | inverse | transposee | trace | rang | A x B | A + B | A^n

  4.6 CALCUL  /  CALCULUS
      Derivee  f'(x)   en un point
      Integrale  de a a b  (methode de Simpson)
      Recherche de racines  (Newton + bissection)

  4.7 STATISTIQUES  /  STATISTICS
      moyenne | mediane | mode | ecart-type | variance | min | max |
      somme | etendue | effectif | percentile
      + regression lineaire (pente, ordonnee a l'origine, R2, correlation)


--------------------------------------------------------------------------------
  5. CALCULS AVEC NOMBRES COMPLEXES
--------------------------------------------------------------------------------

  Tous les calculs utilisent les nombres complexes :

      sqrt(-16)      ->  0 + 4i
      cbrt(-8)       ->  -2
      sqrt(-1)       ->  1i

  Pour la racine cubique reelle d'un nombre negatif, utilisez  cbrt(x).
  Pour la puissance rationnelle, le resultat est la branche principale
  complexe (comportement standard des calculatrices).

--------------------------------------------------------------------------------
  9. PROBLEMES COURANTS  /  COMMON ISSUES
--------------------------------------------------------------------------------

  * Le programme ne s'ouvre pas
      -> Verifiez que le fichier n'est pas bloque : clic droit >
         "Proprietes" > cochez "Débloquer" > OK. Puis relancez.
      -> Right-click > Properties > tick "Unblock" > OK, then run again.

  * "Ouvrir avec" demande une application
      -> C'est un .exe, pas un .py. Lancez-le par double-clic.

  * L'ecran semble fige pendant un calcul
      -> Fermez la fenetre du module concernee (bouton X) et rouvrez-la.

  * The program does not start
      -> Unblock the file (right-click > Properties > Unblock) and retry.

  * Want to change the interface language?
      -> Click the language radio buttons at the top-left of the main window.
