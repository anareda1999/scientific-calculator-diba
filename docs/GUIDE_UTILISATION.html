Guide d'utilisation complet — DIDA Scientific Calculator User Guide

Installation : Aucune installation requise. Python n'est pas nécessaire. Envoyez simplement le fichier ScientificCalculator.exe à votre client.
No installation required! Python is NOT needed — just send the .exe file to your client.

1 Démarrage rapide

  1. Double-cliquez sur ScientificCalculator.exe
  2. Si Windows affiche un avertissement, cliquez sur « Informations complémentaires » puis « Exécuter quand même »
  3. Choisissez votre langue en haut à gauche : Français · English · العربية

Double-click the .exe. If Windows shows a warning, click “More info” then “Run anyway”. Then pick your language top-left.

2 L'interface principale

En haut à gauche

Sélecteur de langue : Français, English, العربية. Le changement est instantané.

En haut à droite

Bouton DEG / RAD : bascule les angles entre degrés et radians (y compris les fonctions inverses).

Barre de modules

Convertisseur · Equations · Graphique · Formules · Matrices · Calcul · Statistiques

À droite

Touche ANS (réutiliser le dernier résultat), CONSTANTES (π, e, c, g, h, k, NA, R) et HISTORIQUE cliquable.

Astuce : cliquez sur n'importe quel calcul dans l'HISTORIQUE pour le réutiliser. Click any previous calculation in the HISTORY to reuse it.

Poids · Devise · Volume · Surface · Distance

4 Nombres complexes

Tous les calculs utilisent les nombres complexes :

SaisieRésultat
sqrt(-16)0 + 4i
sqrt(-1)1i
cbrt(-8)-2

Utilisez cbrt(x) pour la racine cubique réelle d'un nombre négatif. Pour une puissance rationnelle, le résultat est la branche principale complexe (comportement standard des calculatrices).

5 Avertissement Windows

C'est normal — ce n'est pas un virus.

Au premier lancement, Windows peut afficher « Windows a protégé votre PC » (SmartScreen). C'est le comportement normal pour tout programme personnalisé qui n'est pas signé avec un certificat.

Solution : « Informations complémentaires » → « Exécuter quand même ».

On first run Windows may show “Windows protected your PC”. This is NORMAL for a custom, unsigned program — it is NOT a virus. Solution: click “More info” then “Run anyway”.

Si un antivirus le signale, ajoutez une exception pour ce fichier.
